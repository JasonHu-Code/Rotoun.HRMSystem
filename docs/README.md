## 阅读顺序建议

1. **需求清单** → 知道做什么、哪些是 P0
2. **技术方案** → 知道用什么、工程怎么拆
3. **数据库设计** → 知道表怎么建
4. **M0 底座改造清单** → 开工前必读，尤其是数据权限与 Token
5. **接口设计 / 考勤引擎设计** → 写代码时查
